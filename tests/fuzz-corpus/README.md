# Corpus iniziale / Initial corpus

Semi sintetici versionati: PNG grayscale valido, profili validi separati/uniti, JSON duplicato e tipi/numeri non validi. Non sono dati satellitari o crash osservati. LibFuzzer copia/estende il corpus nella cartella di build, senza modificare questi semi. Il PNG è generato con l'encoder standard-library di orbyx_simulate.py.

Versioned synthetic seeds for PNG decoding and actual profile/generation branches. Build-local mutations and crash artifacts remain outside the source corpus. No real satellite imagery or personal data is included.
